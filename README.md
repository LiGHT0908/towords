# towords

A lightweight npm package for converting numeric amounts into human-readable words.

This package was originally developed to simplify invoice generation workflows, where monetary values need to be displayed both numerically and in words for improved readability and compliance.

## Features

* Convert numbers into words
* Suitable for invoices, receipts, and financial documents
* Supports large numeric values

## Use Cases

* Invoice generation systems
* Billing and accounting applications
* Financial reporting tools
* Document automation workflows

## Example

Input:

123

Optput:

One Twenty Three
